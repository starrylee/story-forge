# Hit Formula Spec 爆款内核规范

本规范沉淀短剧/网文爆款的通用创作内核，供各 action 在「商业模式：短剧向」启用时应用。它不是教条，而是**按需启用的节拍约束**——默认不启用，避免污染文学向创作。

## 启用开关

概念卡（concept.md）增加字段：

```markdown
- 商业模式：短剧向 / 通用
```

- **短剧向**：全链路启用本规范的约束（build-world / design-characters / design-plotline / plan-chapters / write-story 均须读取本规范）
- **通用**：本规范不生效，按原有准则创作

## 一、情绪代偿定位（expand-premise 注入）

爆款的终极共性：**不造梦，造代偿**——精确对准某一人群在现实中最稀缺的情绪，用最短周期反复结算。

四大赛道的情绪公式：

| 赛道 | 目标人群现实缺口 | 代偿机制 |
|---|---|---|
| 女频 | 现实婚育中的委屈与不确定 | 确定性的爱与"灭亲"许可 |
| 男频 | 社会性尊严受挫 | 力量碾压的即时兑现 |
| 银发 | 被数字化社会边缘化 | "老祖宗一言九鼎"的权柄回归 |
| 漫剧/脑洞 | 现实重力约束 | 零成本的想象力放飞 |

概念卡须明确：**目标人群 → 情绪缺口 → 代偿机制**，以及情绪结算周期（多长时间兑付一次爽点）。

## 二、封闭小世界原则（build-world 注入）

- 世界观半径收窄到一个**熟人社会权力结构**：一个家族、一个公司、一个村庄、一个四合院
- 封闭空间保证：①冲突密度高（低头不见抬头见）；②人物关系简单，观众 3 集认清所有阵营；③制作成本低
- 没有宏大世界观，只有"熟人社会权力结构"；与剧情无关的设定点到为止

## 三、身份错位引擎（design-characters 注入）

**核心：极端身份错位/信息差是打脸合理性的来源。**

- 主角设定须包含以下其一（或组合）：
  - **马甲流**：表面落魄，实为隐藏大佬（战神/龙王/神医/神豪）
  - **认知降维**：重生/穿越带来的高认知对低认知碾压（现代记忆 vs 年代、前世经验 vs 今生）
  - **辈分/年代错位**：18 岁身体 × 80 岁智慧 × 至高辈分（"太奶奶"式时空代偿）
- 人物档案增加：
  - **隐藏身份**：主角的真面目，以及各角色对其真实身份的认知程度
  - **信息差矩阵**：谁知道什么——信息差既是悬念来源也是打脸燃料
- 配角**功能性脸谱化**：极品亲戚/白眼狼/绿茶/势利眼——恶得不留余地，正是给"断亲""打脸"提供道德许可；配角不做复杂化
- **反派链**：小 Boss 背后永远有更大的反派（恶婆婆→小姑→豪门→更大势力），保证冲突可无限续期
- 反派同样需要合理动机，但动机清晰 ≠ 立体复杂——观众恨得快才爽得快

## 四、黄金公式（design-plotline 注入）

每个情节节点遵循：**冲突 → 反转 → 打脸 → 钩子** 的循环。

- 情节节点须标注：**爽点类型与结算周期**（本章兑付什么情绪、间隔多久）
- 核心冲突须绑定**降维打击合理性**（主角为何必赢：马甲/前世记忆/辈分碾压）
- 人设反转是第一技巧：关键人物可在 3 句台词内完成认知颠覆
- 主线一根筋，无支线干扰；前 3 章给完所有核心人设，读者第一集就知道故事走向——**确定性本身就是付费动力**
- 白眼狼恶有恶报的因果结构是标配：观众需要"善恶终有报"的安全感

## 五、章级节拍（plan-chapters 注入）

- 每章四要素升级为五要素：目标 / 冲突 / 转折 / 钩子 + **爽点结算**（本章兑付的具体情绪时刻）
- 节奏检查增加硬性告警：**连续 2 章无打脸或无信息差变现即失衡**
- 每章结尾断在"打脸前 0.1 秒"——钩子即付费卡点
- 开篇 3 章定生死：第 1 章直接打脸/背叛/绝境，第 2 章金手指上线，第 3 章第一次小逆袭+大钩子

## 六、正文节拍（write-story 注入）

只加节拍约束，不干预文风本身：

- **动作戏优先**：不写静态心理独白，用动作与对话承载情绪
- **嘴替台词**：主角说观众不敢说的话——一针见血、当场掀桌、不内耗
- 每章至少一次情绪兑现（打脸成功/信息差变现/代偿时刻）
- 对话承载张力，删除不推进任何东西的寒暄
- 短句节奏、高换行、强对白（网文阅读习惯），但不牺牲基本文学质量
